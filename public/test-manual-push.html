Manual DevTools Push Test

To test from DevTools Application tab:
  1. Open DevTools (F12) → Application tab
  2. Click "Service Workers" in the left sidebar
  3. Find your service worker (should be from firebase-messaging-sw.js)
  4. Under the service worker, find the "Push" text field
  5. Copy this test payload and paste it: 
    {
  "notification": {
    "title": "🔔 Manual Test",
    "body": "This is a manual push test from DevTools!",
    "icon": "/pwa-192x192.png"
  },
  "data": {
    "link": "/",
    "type": "test"
  }
}
  6. Click the "Push" button in DevTools
  7. You should see a notification appear!
